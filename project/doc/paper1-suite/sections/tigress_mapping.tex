\section{TIGRESS-NCR Parameter Mapping}
\label{sec:tigress_mapping}

\subsection{TIGRESS-NCR Input Parameters}

[SKELETON] The \TIGRESS\ framework \citep{2024ApJ...972...67K} solves the equations
of ideal MHD with self-gravity and explicit thermochemistry in a local shearing-box
geometry. The initial conditions are specified by the following parameters:
\begin{itemize}
  \item $\Sgas$: total gas surface density
  \item $\Sstar$: stellar surface density
  \item $\zstar$: stellar scale height
  \item $\Omrot$: orbital frequency
  \item $\rhodm$: dark matter volume density at the midplane
  \item $\qshear$: shear parameter $q \equiv -d\log\Omrot/d\log R$
\end{itemize}

\subsection{Fiducial Physics Parameters}

The first simulation suite holds all physics parameters at fiducial solar-neighborhood
values: metallicity $\Zg = 1$, dust-to-gas ratio $\Zd = 1$, and standard feedback
and population-synthesis assumptions. Extension to physics parameter variations is
described in \autoref{sec:discussion}.
